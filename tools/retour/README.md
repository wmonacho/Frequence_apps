# Bouton retour dans les apps

`ajouter_retour.py` ajoute à chaque app (Matin, Job, Révision, Trail et les apps Coda) un petit module :
le bouton retour d'Android et le glissement depuis le bord gauche sur iPhone ferment d'abord ce qui est ouvert
(article, leçon, réglages), puis reviennent à l'écran d'accueil de l'app, au lieu de quitter l'app.

À relancer sur le `index.html` d'une app si elle est régénérée (par exemple Charpente ou Socle avec leur `build.py`).
Fréquence Nid gère déjà l'historique elle-même.
